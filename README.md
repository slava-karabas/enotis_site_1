# ЭНОТИС · Панель №1

Лента без оплаты и магазина. Кандидат кода **2.0.0** для чистой установки и проверки.

- [Объединённая спецификация **2.2**](docs/spec-2.2.md) — все три ядра, подробные требования и статус реализации.
- [Документация](docs/README.md) и [краткая инструкция](docs/quick-start.html).
- [Установка и подключения](docs/setup.md).
- [Оформление панели](docs/admin-style.md).
- [Архив прежних документов](docs/archive/README.md).

Одинаковый интерфейс: дерево слева, форма по центру, настоящий предпросмотр справа. №1 — без оплаты; №1.2 — оплата без магазина; №2 — редактор, оплата и магазин. Подарочный конструктор находится в «Содержимом» только №2.

**2.2 — редакция спецификации, 2.0.0 — версия кода.** Актуальная рабочая ветка — `work/unified-admin-2026-10-27`. Обновление документации и GitHub не означает выкладку сайта. Непокрытые сценарии и расхождения с требованиями честно перечислены в разделе 21.3; это не подтверждение готовности всех функций к продажам.

Внешние сервисы требуют собственной настройки. У магазина нет подключённого онлайн-эквайринга: заказы оформляются для ручного согласования оплаты/доставки. Почта, CRM и ИИ проверяются на реальном хостинге отдельно. Канал автоматического перехода между разными продуктовыми идентификаторами отключён.

Проверки разработки: `tests/run.sh` (PHP 8.1+, SQLite, GD, ZIP, mbstring, cURL; №2 также Python 3). Клиентские базы и секреты в документацию не входят.

### Страница путеводителя · 30.10.2026

Рабочая ветка ядра №1: общий рендер фото/описания со святынями, обычный текст посещения, переносимый блок «Контакты» и открытая карта собственных координат страницы. Краткий норматив: [docs/monastery-page-standard.md](docs/monastery-page-standard.md), реализация — спецификация 2.2 §6.3. Профиль путеводителя не содержит продукции и оплаты; прежние информационные карточки универсального редактора сохраняются. Изменения №1.2/№2 отложены. Клиентский контент, хостинг и Google Диск этим этапом не обновляются.
