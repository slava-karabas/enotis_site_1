# Ядро №1 · 2.0.1

Чистый код без пользователей, паролей, заказов и контента Грузии.
Путеводитель и витрина. Продукция включается в «Настройки сайта → Иконка и обложка». Без оплаты.

Установите PHP 8.1+ с PDO SQLite, GD, ZIP, mbstring и cURL. Корень сайта public/. Первый вход: /admin/install. На PHP-FPM настройки загрузки находятся в .user.ini; ограничения самого хостинга проверяются отдельно.

Общий стандарт карточки: docs/wine-card-standard.md. Сверка редактора: docs/admin-parity.md.
