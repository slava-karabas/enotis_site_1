# ЭНОТИС · Панель №1

Лента без оплаты. Кандидат ядра 2.0.0 для чистой установки и проверки.

- [Краткая инструкция](docs/quick-start.html) — реальный интерфейс и основные действия.
- [Утверждённый функционал](docs/admin-spec-2.0.md).
- [Установка и подключения](docs/setup-2.0.md).
- [Оформление панели](docs/admin-style.md).

Слева дерево, в центре форма, справа настоящий предпросмотр. Общие блоки и редактор одинаковы; каталог и конструктор доступны только №2, оплата отсутствует в №1.

Внешние сервисы выключены до настройки. Магазин принимает заказы для ручного согласования оплаты и доставки; онлайн-эквайринг не подключён. Запись кода в GitHub не выкладывает сайт. Более ранние спецификации и инструкции отражают предыдущие версии.

Проверки: `tests/run.sh` (PHP 8.1+, SQLite, GD, ZIP, mbstring, cURL; для №2 также Python 3). Данные проверок изолированы. Автоматический переход с прежних продуктовых идентификаторов не включён.
