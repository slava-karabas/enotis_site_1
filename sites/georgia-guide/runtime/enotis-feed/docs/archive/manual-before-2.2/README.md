# Инструкции панели

Оформление: ../admin-style.md. Материалы demo/ — условные синие иллюстрации для отдельной демонстрационной установки. Реальный клиентский контент не включать.
Снимать настоящую компьютерную панель с актуальным CSS, без перекрашивания снимков. В инструкции №1.2 убрать раздел оплаты; остальные действия общие. В №2 добавляются только согласованные функции магазина.
Исторические PDF/макеты со старым оформлением не являются актуальной инструкцией. Актуальная общая инструкция: admin-manual.pdf и admin-manual.html в этой папке. Локальная копия: «Панель управления сайтом — инструкция.pdf» в видимой папке проекта. Google Диск пока не обновлялся.
