# Единый стиль панелей управления и их инструкций

Утверждено Славой 26.10.2026 для №1, №1.2 и №2. Заменяет прежние решения о сливовых и голубых элементах управления. Функциональные различия панелей сохраняются.

| Роль | Значение |
|---|---|
| Фон рабочей области | #F5F5F5 |
| Светло-серые панели / дерево | #EEEEEF |
| Поля ввода, карточки, форма | #FFFFFF |
| Основной текст | #303C46 |
| Вторичный текст | #5F6E7A |
| Тонкая рамка | #D9E1E6 |
| Основная кнопка / включённый переключатель | #FFD12A |
| Наведение основной кнопки | #EDBF18 |
| Светлый ореол | #FFF8D9 |
| Текст жёлтой кнопки | #303C46 |
| Ссылки и текстовые действия | #303C46; не жёлтые буквы на белом |
| Фокус клавиатуры | графитовая рамка + светлый жёлтый ореол |
| Шрифт | Arial, Helvetica, sans-serif; lining-nums tabular-nums |

Красный остаётся для ошибок и удаления, зелёный — для подтверждения. Основная жёлтая кнопка не заменяет смысловые цвета ошибок. Макет: дерево слева / форма по центру / предпросмотр справа. Не менять согласованный UX и бизнес-логику при смене темы.

В инструкциях показывать настоящую компьютерную панель из того же кода с этой темой. Не перекрашивать скриншоты и не подменять живой предпросмотр нарисованным интерфейсом. Демонстрационные иллюстрации: прохладный синий (#E0EDF7, #9ABBD6, #6287AD, #8ABED4, #CDDEE9), без клиентского наполнения. Голубые иллюстрации не означают голубую тему панели. Реальные фотографии пользователей не перекрашивать.

Документы-инструкции этих панелей используют белую страницу, графитовый текст и жёлтые акценты; Arial целиком. Общие служебные обзоры сохраняют отдельно согласованные пастельные бежевые/голубые варианты. Витрины сайтов сохраняют собственное оформление; изменения ограничены CSS панели и её инструкциями.

Запись в GitHub не подтверждает выкладку на хостинг. Изменения готовятся в ветках; запуск деплоя и публикация обновлений — отдельное действие.
