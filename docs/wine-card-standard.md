Название: Playfair Display Medium 500, 24px, line-height 1.2; телефон до 599px — 22px. Использовать локальный файл из утверждённого образца; без искусственного жирного начертания, сжатия и растягивания. Arial для названия вина не применяется.
Характеристики: Golos Text Regular 400, 16px, line-height 1.55; телефон — 13px. Между названием и характеристиками 12px, без зарезервированной пустой строки под заголовком. Пять строк без дополнительных межабзацных отступов. Цифры lining-nums tabular-nums.
Отступы блока описания: 22px сверху и по бокам, 20px снизу; на телефоне 16px сверху/снизу и 12px по бокам. Карточки одинаковой высоты в ряду; пустая заглушка не уменьшается из-за отсутствия покупки.

## Название и строго пять строк

Реальное вино: собственное название, затем значения без префиксов «Страна:», «Сорт:» и т. п.:
1. Страна (пример: Грузия).
2. Производитель: название монастыря, хозяйства или винодельни (пример: Монастырь Дариали).
3. Тип/сладость и цвет одной строкой (пример: сухое, красное).
4. Сорт винограда (пример: Саперави).
5. Год урожая (пример: 2025).

Пример названия из макета: Dariala Saperavi Qvevri. Это пример заполнения, не источник для присвоения характеристик другим винам. Подтверждённое вино без фотографии сохраняет своё название и известные данные, использует бутылку Henotis. Неизвестные поля оставляются названиями полей, не выдумываются.

Пустая карточка-шаблон: название строго «Название вина»; ниже пять отдельных строк строго «Страна», «Монастырь» (для хозяйства — «Винодельня»), «Тип и цвет», «Сорт», «Год». Та же типографика, первая буква названия бордовая. Фотография — утверждённая Henotis.
На плитке нет дополнительных абзацев, предупреждений и подписи о демонстрационном изображении. Пояснение о Henotis находится в подробностях: это демонстрационная бутылка, а не этикетка производителя. Для пустого слота конкретное вино не подтверждено.

## Бутылки

Единый холст 1200×1500, фон #F7F5F0. Видимая бутылка высотой 1230px, поля сверху и снизу по 135px. Сохранять пропорции, линию основания и мягкую контактную тень. Те же параметры у Henotis. Без обрезки, растягивания, multiply, чёрных/серых подложек, статусов и текста поверх изображения. Сохранять идентичность настоящей этикетки. Изображение показывать целиком.

## Действия

Круглый плюс диаметром 36px, рамка 1px, знак 24px; всегда открывает подробности, включая заглушку с минимальными полями. В информационном режиме — плюс справа внизу.
В магазине у настоящего товара цена слева и плюс справа в одной строке; ниже через 14px большая кнопка «В корзину» на всю ширину, высота минимум 44px, скругление 99px. Цена Golos Text 500, 21px; кнопка Golos Text 400, 15px. От характеристик до области действий минимум 24px; действия прижаты к низу одинаковых карточек.
Пустой слот не продаётся: без цены и «В корзину», с работающим плюсом. Не добавлять пока «Информация готовится», дополнительные кнопки и декоративное заполнение пустоты: это только обсуждалось, не утверждено.

Один общий компонент для настоящего вина, временной фотографии и заглушки: `app/wine_card.php`, `app/views/wine_card_text.php`, оформление `public/assets/css/product-cards.css`. Каталог с боковым фильтром — три колонки на компьютере.
Стандарт общий для публичных сайтов на ядрах №1, №1.2, №2. Путеводитель без продукции остаётся без товарного блока. Витрина — без корзины.
