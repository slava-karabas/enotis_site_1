# Как добраться — общий блок

Карта на всю ширину, под ней единая полоса: название и адрес слева, одна кнопка маршрута справа. До 600 px — карта, название/адрес и кнопка на всю ширину, сверху вниз. Высоты карты: 390 / 320 / 280 px.

В редакторе используются существующие поля названия, адреса (place), широты и долготы. Схема данных не меняется. Предпросмотр и публичная страница используют directions-card.php; place.php подключает его в поп-апе, directions.php — на полной странице.

Точка подписана постоянно, приближение 15. Карты нескольких мест сохраняют прежние группировку, приближение и действия. Без координат карта и маршрут не создаются. Сервис Google/Яндекс берётся из существующей настройки ленты.

Разворачивание карты сохраняет Escape и возврат фокуса. В поп-апе Escape сначала закрывает развёрнутую карту. Без JavaScript остаются название, адрес и рабочая ссылка маршрута.

Проверка: PHP 8.1, tests/directions-card.php; браузер 1552/768/390 px, разворачивание, Escape, возврат фокуса. Изменение кода в GitHub само по себе не означает обновление установленных клиентских сайтов.
