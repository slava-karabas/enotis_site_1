# Панели ЭНОТИС — единая спецификация 2.0
Утверждено Славой в чате панели №2, 27.10.2026. Первично для текущей разработки; старые документы описывают историю.

## Продукты
- №1: лента без оплаты и магазина.
- №1.2: лента с оплатой услуг и пожертвованиями; без магазина.
- №2: общий редактор, оплата, магазин.
Существующие продуктовые идентификаторы старых сборок не означают корректное распределение номеров. Новые версии имеют отдельную идентичность; автоматический переход старых установок запрещён до проверки миграции на копии.

## Общий интерфейс
Arial, серые панели #EEEEEF/#F5F5F5, белые поля, графит #303C46, жёлтые кнопки #FFD12A. Дерево слева, форма по центру, живой предпросмотр справа. Не менять оформление витрины. Подразделы — типы редактируемого содержимого, не вторые копии данных.

## Меню №2
1. Шапка: название, логотип, меню, языки.
2. Содержимое: тексты, фотографии, плитки, страницы плиток, вкладки, фильтры плиток, карта, услуги, подборка товаров, подарочный конструктор.
3. Магазин: каталог, категории и фильтры, поиск и сортировка, корзина и оформление, заказы.
4. Оплата: услуги, пожертвования, покупки.
5. Подвал: организация и реквизиты, контакты и адреса, соцсети, документы, Cookies, авторские права.
6. Интеграции: уведомления, CRM и автоматизация, API и доступы, ИИ-обработка, аналитика, журнал обмена.
7. Настройки сайта: языки сайта, иконка и обложка, перенос сайта, резервные копии, обновление.
В №1/№1.2 отсутствует магазин и связанные с ним блоки. В №1 отсутствует оплата.

## Данные и блоки
Карточка товара едина: название, подпись, фото, описание, характеристики, цена. №2 дополняет её категорией, фильтрами и доступностью к заказу. Производитель — поле, упаковка — настройка подарочного конструктора. Подборка выбирает существующие товары без повторного наполнения. Конструктор находится только в «Содержимом»; состав и сумма проверяются сервером.
Фильтры плиток отбирают единый список; вкладки переключают разные наборы блоков. Имена уровней, вариантов и «Все» редактируются.

## Интеграции
В магазине заказ и исходящее событие сохраняются атомарно. В лентах очередь и настройки подготовлены; отдельного источника заявок сейчас нет. Доставка из очереди отдельной CLI-задачей по расписанию, не во время ответа покупателю. Почта владельцу и подписанный HTTPS webhook; ограниченные повторы, журнал без секретов. Получатель устраняет дубликаты по id события. Ключи не попадают в экспорт. API включается явно, токен хранится хешем, разрешения чтения и изменения статуса раздельны. API не принимает подтверждение оплаты и изменение цен.
ИИ-обработка: существующие Claid/PhotoRoom; подключение в «Интеграциях», кнопка «ИИ-обработка» у фото, оригинал сохраняется. Не обещать результат для любого исходника.
Оплата магазина не считается подключённой без выбранного провайдера, серверного подтверждения и проверок. Внешние API/CRM/почту не включать без настроек владельца.

Чистая установка, доступ/CSRF, сохранение и предпросмотр, права API, очередь/повторы/дубликаты, каталог/корзина/конструктор, перенос и восстановление. Краткие инструкции по реальному UI, чёткие снимки интерфейса. GitHub — ветки/PR без автоматической выкладки; хостинг отдельно. Актуальные документы и пакеты на Диске по новой команде Славы, история в архиве; код и данные покупателей в публичные материалы не копировать.
